Separate an individual run trace from aggregate monitoring and from evaluation of answer quality. The catalog includes these overlapping roles; shortlist by the evidence you need to diagnose your application.

Explain one failed agent run

Check whether the documented integration records the model/tool sequence, errors and timing needed to reconstruct your workflow. Test a failed tool call as well as a successful run.

Track production behavior

Define which latency, error and cost signals matter, then verify export, retention, redaction and deployment options against the selected version.

Detect a quality change

Choose explicit quality labels or reference data and a review process. A change in a dashboard metric needs investigation before being described as model drift or answer degradation.
